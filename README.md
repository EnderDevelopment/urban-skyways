# Urban Skyways

Urban Skyways is a Minecraft plugin designed to enhance the city-building experience by providing tools for constructing buildings and vehicles like cars, planes, and ships. It offers a Building Wand that allows players to quickly place blocks, and it includes a simple command to greet players. This plugin is perfect for those who want to expand their Minecraft world with more interactive and immersive city-building features.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Obtain the Building Wand by using the `/ciao` command or by crafting it with specific materials.
2. Right-click on a block with the Building Wand to place a block above the clicked block.
3. Use the `/ciao` command to greet yourself or other players.
